Connect this example to the training model
The frozen WAN VAE produces 16 latent channels. Each 1 × 2 × 2 patch contains 64 latent values. One observation-mask channel adds four values, so the input projection maps 68 values to 384 features. The velocity output projection produces 64 values per patch. The training clip has 17 frames at 128 × 128 pixels, with the first five frames observed. This explorer uses one channel and four values per patch to make packing and unpacking easy to inspect.

Inspect the illustrative features
Each patch supplies six handcrafted features from its mean, top-to-bottom difference, and left-to-right difference. Q and K share those features, normalized by their root mean square. Three coordinate rotations act on three pairs of features. Values are the patch means. The training model learns its projections and uses 64 features per head across six attention heads.
q, k = RMSNorm(handcrafted_patch_features)
q, k = rotate_pairs(q, k, positions)  # optional in this demo
weights = softmax(q @ all_keys.T / sqrt(6))
output = sum(weights * patch_means)

  


  

    
3. Move between a clean latent and noise

    
Change flow time t to mix the two arrays. This 16 × 16 pattern stands in for one latent channel. The displayed colors clip values to [−2, 2]; the arithmetic uses the full values.

    

    

    
zₜ = (1 − t)z + tε    v_target = ε − z

    

    
Training gives the network zₜ, t, and the conditions, then compares its output with v_target. Sampling starts at t = 1 and uses the learned velocity to step toward t = 0. This slider displays training interpolation.
