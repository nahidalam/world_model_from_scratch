Transition and rollout playground

This world is a one-dimensional track. The observation contains the ball's position and speed. The action is to slow down, keep speed, or speed up. The model predicts the next observation.

What to do

  1. Choose an action and select one or multiple predicted futures.
  2. Select Predict next observation to see one transition.
  3. Select Use prediction as next step, then repeat to build a rollout.
