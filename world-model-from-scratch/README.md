# World Models from Scratch

*Building Modern World Models from First Principles*

This book is a hands-on guide to world-model foundations, running a pretrained
model, evaluating results, building a small model, and exploring modern
architectures.

## Code

Reusable code is in `src/world_models/`, tests in `tests/`, self-contained
explorable demos in `interactive/`. Install dependencies with:

```bash
pip install -r requirements.txt
pip install -e .
```

Different chapters might have additional GPU or system requirements, described
in the corresponding chapters.
