# World Models from Scratch

_Building Modern World Models from First Principles_

This book is a hands-on guide to world-model foundations, running a pretrained model, evaluating results, building a small model, and exploring modern architectures.

## Chapters

* [Chapter 1: Understanding World Models](chapters/chapter_01/)
* [Chapter 2: Running a Pretrained World Model](chapters/chapter_02/)
* [Chapter 3: Evaluating World Models](chapters/chapter_03/)
* [Chapter 4: Building a World Model from Scratch](chapters/chapter_04/)
* [Chapter 5: Architectures of Modern World Models](chapters/chapter_10/)

## Code

Reusable code is in `src/world_models/`, tests in `tests/`, self-contained explorable demos in `interactive/`. Install dependencies with:

```bash
pip install -r requirements.txt
pip install -e .
```

Different chapters might have additional GPU or system requirements, described in the corresponding chapters.
